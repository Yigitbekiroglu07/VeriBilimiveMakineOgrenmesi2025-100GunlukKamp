📘 100 Days of Data Science & Machine Learning (2025)
This repository contains a complete 100-day learning program focused on Python, Data Science, Machine Learning, and SQL.
It includes Jupyter notebooks, datasets, SQL examples, and practical exercises designed to build real-world data science skills step-by-step.

🚀 How to Use
▶️ Run Jupyter Notebooks
1. Install dependencies:
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
2. Start Jupyter:
jupyter notebook
▶️ Run SQL Example Projects
python PythonSQLExamples/main.py
